# Mandelbrot Set Visualizer

An interactive Mandelbrot set visualizer built using JavaScript and p5.js.

## Controls

* **Arrow Keys**: Pan around
* **A / S**: Zoom in / Zoom out
* **F / D**: Increase / Decrease detail level (max iterations)

## Tech Stack & Concepts

* **JS & p5.js**
* **Direct pixel manipulation** (`loadPixels` / `updatePixels`)
* **Complex number math** & HSB color mapping
